01AI calling
2026

A SIP dialer that lives inside other CRMs

Sales teams want to call from the CRM they already use. I built a WebRTC dialer with SIP.js and embedded it in five CRMs, each through that CRM's own SDK.

  • Outbound and inbound calls, ring and dial tones, microphone selection, noise suppression and live call summaries.
  • HubSpot Calling Extensions SDK and Pipedrive App Extensions SDK, covering the handshake, click-to-call, incoming-call events and call-state sync.
  • A Salesforce app built with Lightning Web Components, Apex and Open CTI. Zoho custom actions come with a Deluge script generator.
  • Freshworks workflows that queue AI calls through channel webhooks.
  • Automatic call-agent setup: each user's SIP credentials are matched to channel regions, and missing agents are created as soon as the CRM user is known.

02Auth
2026

One OAuth backend for every CRM

Each CRM handles tokens differently. I built one Node.js service that handles all of them.

  • Per-CRM client credentials, discovered automatically, with user-level scoping.
  • Automatic token refresh with retry on 401/403, safe to run concurrently.
  • Refresh tokens are never sent in API responses.
  • CRM-specific lead lookup and mapping, so the dialer always knows who is on the line.
